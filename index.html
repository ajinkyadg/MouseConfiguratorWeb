This browser can't talk to the mouse

MouseConfig uses WebHID, which only desktop Chrome, Edge, Brave, and Opera support. Safari, Firefox, and phone or tablet browsers can't connect — open mouseconfig.app on a computer in one of those browsers. You can still browse the settings and import or export profiles here.

On macOS 26.6.2 or later? Apply needs a one-time workaround.

Show stepsHide

Since macOS 26.6.2, Apple only lets privileged apps write settings to this mouse, so a normally-launched browser can connect but every Apply fails with “Failed to write the feature report.” Nothing is wrong with your mouse or this page. The workaround is to open Chrome with administrator rights, just for this:

  1. Open Terminal (Spotlight → “Terminal”). Your normal Chrome can stay open.
  2. Paste this command, press Return, and enter your Mac password when asked: 
    sudo "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --user-data-dir=/tmp/chrome-root https://mouseconfig.app/
  3. A separate Chrome window opens on this page. Click Connect to M913, then Apply Configuration.
  4. When you’re done, quit that Chrome window (⌘Q) and close Terminal. Your settings stay saved on the mouse.

Only use that window for MouseConfig. A browser running with administrator rights has full access to your Mac, so don’t browse anywhere else in it. The --user-data-dir part keeps it in a throwaway profile, separate from your normal Chrome, so your bookmarks and logins are never touched. Not using Chrome? Edge and Brave work the same way — swap in their app path.

Preview mode — no mouse connected. You can edit, import and export profiles freely down here; connecting unlocks Apply so the settings reach the hardware.

Profile

Have a .jmk file (Redragon's Windows profile export) shared by someone on a forum or Discord? There's no way to open a .jmk file on Mac or Linux with Redragon's own software — import it here instead to bring in its button mappings. DPI, polling rate, and LED aren't decoded yet, so those stay at defaults. Just want to see what's inside a .jmk file without connecting a mouse? Try the standalone .jmk file decoder.
