This browser can't talk to the mouse

MouseConfig uses WebHID, which only desktop Chrome, Edge, Brave, and Opera support. Safari, Firefox, and phone or tablet browsers can't connect — open mouseconfig.app on a computer in one of those browsers. You can still browse the settings here.

New — not yet hardware-verified

M908 support was built from public protocol documentation, not a confirmed working device — unlike the M913, this hasn't been tested on real hardware yet. DPI/LED/report-rate and button mapping should be structurally correct, but if something doesn't work as expected, that's expected until the first real test.

Onboard Profiles

The M908 stores five profiles on the mouse and switches between them with its profile button. Pick one to edit — every section below edits only that profile.

Your five profiles are saved in this browser automatically. This page can't read what's currently on the mouse, so if you set profiles up in Redragon's Windows software, recreate them here (or keep an export) before applying.
