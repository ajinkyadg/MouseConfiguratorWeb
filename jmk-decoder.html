.jmk File Decoder

Open and read a Redragon .jmk profile's button mappings on Mac or Linux — entirely in your browser.

What is a .jmk file?

A .jmk file is a mouse profile exported by Redragon's official Windows configuration software — it stores button mappings, DPI stages, and lighting settings. Redragon doesn't publish a Mac or Linux version of that software, so if someone shares a .jmk file with you (a forum post, a Discord message, a saved backup), there's normally no way to open it outside Windows. This page decodes its button mappings directly on your device — nothing is uploaded anywhere, and it works without connecting a mouse.

What this doesn't decode (yet)

DPI stages, polling rate, and LED settings aren't decoded yet. Buttons bound to a named custom macro (a recorded sequence of keystrokes, rather than a single key combo) use a different encoding this tool doesn't read yet either — those show up as "not decoded" below.
